# 실제 Apple Watch 검증 — 미실행

대상: Apple Watch Series 10 Cellular, watchOS 11 이상. 이 문서의 모든 항목은 실제 기기에서 측정하기 전까지 **미검증**입니다. 개인 좌표, 가족 링크, 기기 비밀이 로그나 스크린샷에 포함되지 않도록 합니다.

- [ ] Xcode에서 독립 Watch 앱을 서명·설치하고 위치 권한, 백그라운드 Location updates 및 재실행 후 안전한 재개를 확인한다.
- [ ] Apple Workout을 실행하지 않고 공유를 시작해 관측과 웹 지도 표시를 확인한다.
- [ ] iPhone을 범위 밖에 두고 Watch Wi-Fi를 끈 상태에서 셀룰러만으로 위치 업로드를 확인한다.
- [ ] 화면을 잠들게 하고 30분 이상 위치 관측 및 백그라운드 지속성을 측정한다.
- [ ] Apple Workout을 동시에 실행하여 30분 이상 같은 검증을 반복한다.
- [ ] 부스트 버튼의 입력 햅틱, 새로운 GPS 관측과 전송 시도, 재입력 시 60초 연장, 자동 정상 모드 복귀를 확인한다. 실제 관측 및 수신 간격을 측정한다.
- [ ] 가족 지점 설정·덮어쓰기·삭제가 다음 성공적인 Watch 응답 뒤에만 반영되고 직선 거리 또는 `--`와 오래된 상태가 정확한지 확인한다.
- [ ] LTE를 잠시 끊고 이동한 다음 복구한다. 원래 관측 시각을 보존해 재전송하고 중복 없이 표시하는지 확인한다.
- [ ] 공유 중지 후 전송이 중단되고 웹이 종료 상태로 바뀌는지 확인한다. 오프라인 중지도 재시도한다.
- [ ] 1시간, 2시간, 4–5시간 순으로 실행한다. 4시간 뒤 배터리 20% 이상은 목표이며 측정 전까지 달성했다고 주장하지 않는다.
